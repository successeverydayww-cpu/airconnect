📐 Structure — the global standard arrangement

1. Entry flow (login)

  1. Logo splash — 1 second, brand mark only (like WhatsApp/Telegram)
  2. One-screen signup: big logo, one input (+country auto-detected), one button "Continue". No menus, no choice overload
  3. OTP → straight into Chats, logged in forever
  4. Name + optional photo on first run — skippable, never blocks entry

2. Main app — 4 bottom tabs

  1. Chats = home. Avatar, name, last message, time, unread badge. New-chat FAB bottom right
  2. Status — circle strip, green rings unseen / gray seen, camera FAB
  3. Calls — history with in/out/missed icons, dialpad FAB
  4. Settings — profile row on top, then account/privacy/notifications/dark-mode

Rule: navigation lives in ONE place (bottom tabs), create-actions float (FAB), profile hides in Settings. Our app already matches ~70% — remaining: Chats as default home, consistent top headers, tab order.

3. The 60-30-10 color rule

60% neutral background (white / charcoal #111B21) · 30% surface tones (rows, bubbles, input bar) · 10% ONE brand accent everywhere (FAB, rings, badges, buttons). Global apps never use a different color per feature — one accent, consistently.

4. Typography & spacing

System font · 13px body, 11px previews, 10px timestamps · 12px padding · 12px bubble radius · 16px FAB radius. These exact numbers are why WhatsApp feels "instantly known".
