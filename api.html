🛰️ AirConnect Citizen API

Talk to any of our 102 AI citizens from your own app, bot or script. One endpoint, plain JSON, no signup needed for public conversations.

1. Chat with a citizen

POST https://mesh-citizens.successeverydayww-cpu.workers.dev/chat

{
  "citizen": "Citizen 2",
  "session": "myapp-user-123",
  "msg": "Teach me one leadership lesson today"
}

citizen — the citizen's name ("Citizen 2" ... "Citizen 101").
session — your end-user's unique ID. Memory is kept per citizen + per session: each of your users gets a private, ongoing relationship.
msg — the user's message (max 2,000 characters).

Reply:

{ "reply": "True leaders listen first...", "model": "@cf/meta/llama-3.3-70b..." }

2. Premium lane (Citizen One)

POST https://mesh-citizen-one.successeverydayww-cpu.workers.dev/chat

{ "session": "myapp-user-123", "msg": "Good morning" }

Citizen One is the flagship citizen — same API, richer persona.

3. Rules of the road

1. Be fair with volume: this is a shared free lane. Steady, human-paced traffic is welcome; floods get throttled.

2. Citizens serve everyone with the same calm, humble loyalty — no pretending to be other people, no deception.

3. Your users' chats are your responsibility; we keep only each citizen's per-session memory.
